# SQL 审计规范要点

参考 OWASP、CWE、阿里巴巴 Java 开发手册中的数据库规约和常见数据库工程实践。重点关注：

| 维度 | 检查点 |
|---|---|
| 安全性 | SQL 注入、动态拼接、权限最小化、敏感字段明文、审计日志、备份泄露 |
| 正确性 | 事务边界、隔离级别、幂等性、唯一约束、空值语义、时区和精度 |
| 性能 | 索引命中、慢 SQL、分页方式、N+1 查询、大事务、锁等待、批量操作 |
| 可维护性 | 命名规范、DDL 变更可回滚、字段注释、版本化迁移、兼容发布 |
| 可靠性 | 连接池配置、超时、重试、死锁处理、读写一致性、灾备恢复 |

高优先级规则：

- 禁止直接拼接用户输入构造 SQL；必须使用预编译参数或安全查询构造器。
- 生产账号必须最小权限，禁止应用账号具备不必要的 DDL/超级权限。
- 金额、密钥、证件号、手机号等敏感字段必须按合规要求加密、脱敏或访问审计。
- 表结构变更必须有迁移脚本、回滚策略和大表变更评估。
- 慢 SQL 和核心交易 SQL 必须有执行计划证据。
